# ⏳ زمن النجاح – SuccessTime

تطبيق ويب متكامل لإدارة الوقت والمهام، مع نظام دعم وعضوية ذهبية.

## ✨ الميزات

- 🕐 ساعة رقمية ذهبية
- 📋 إدارة مهام حسب الأولوية (عاجل، مهم، عادي)
- 💡 نصائح يومية مخصصة
- 👤 ملف شخصي (اسم + هدف)
- 👑 نظام عضوية ذهبية (مدعوم عبر Ko-fi)
- ☕ زر دعم سريع
- 📱 يعمل على جميع الأجهزة

## 🚀 النشر

1. ارفع الملفات إلى مستودع GitHub
2. فعّل GitHub Pages
3. شارك الرابط!
